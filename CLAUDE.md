# CLAUDE.md - AIOS Project Guidelines

## Project Vision
This repository is the blueprint for the **AI Operating System (AIOS)**. It defines a high-precision workflow for AI agents to deliver professional-grade software and design.

## Core Operating Protocol
Every task must follow this linear flow:
**`Observation` $\rightarrow$ `Rigueur` $\rightarrow$ `Expertise` $\rightarrow$ `Exécution` $\rightarrow$ `Preuve`**

1. **Observation**: Invoke `task-observer` to align with project principles and log insights.
2. **Rigueur**: Apply Karpathy's principles (Prudence > Vitesse, Minimalist, Explicit Assumptions).
3. **Expertise**: Load the relevant skill (`engineering-efficiency` for code, `awwwards-design-pro` for UI).
4. **Exécution**: Surgical edits. Zero superfluity.
5. **Preuve**: Validate using `Playwright` or a visual Artifact.

## Technical Standards
- **Code**: Maintainability first. Avoid over-abstraction.
- **Design**: Premium aesthetics (Awwwards style). Focus on micro-interactions.
- **Sourcing**: Always verify technical claims via `Perplexity` or `Firecrawl` before implementing.
- **Verification**: No task is "Done" until a verifiable proof (test/screenshot/log) is provided.

## Memory & Persistence
- The `project-operating-protocol.md` is the source of truth for agent behavior.
- All skill observations must be written to the absolute path defined in the `task-observer` config.
