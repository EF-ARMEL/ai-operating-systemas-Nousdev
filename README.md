# 🌌 AI Operating System (AIOS)
### *The Ultra-High-Performance Framework for Autonomous AI Engineering & Design*

Welcome to the **AI Operating System**, a professional-grade architecture designed to transform a standard LLM into a high-precision autonomous agent. This project serves as a blueprint for setting up an environment where **Sourcing**, **Engineering**, **Design**, and **Validation** are handled by specialized tools and a rigorous protocol.

## 🚀 The Core Concept
AIOS moves away from "prompting and hoping" to a **Verifiable Workflow**. It integrates a suite of MCP servers and specialized skills to ensure that every line of code and every pixel of design is backed by real-time data and professional standards.

## 🛠 The Stack at a Glance

### 🧠 The Brain (Intelligence & Sourcing)
- **Perplexity MCP**: Real-time web intelligence and technical validation.
- **Firecrawl MCP**: Deep web extraction and documentation analysis.
- **Playwright MCP**: Live web interaction and visual QA.
- **OmniRoute**: Multi-model orchestration for cross-verification.

### 🎨 The Eye (Design & Creativity)
- **Awwwards Design Pro**: High-end UI/UX standards.
- **Higgsfield Suite**: Professional AI generation for images, video, and branding.
- **UI Frameworks**: Integrated support for Shadcn, MUI, Ant Design, and GSAP.

### ⚙️ The Hand (Engineering & Rigor)
- **Engineering Efficiency**: Focus on maintainability and performance.
- **Karpathy Rigor**: Minimalist, surgical, and evidence-based implementation.
- **Task-Observer**: Meta-skill for autonomous self-improvement.

## 📖 Quick Start

1. **Install MCP Servers**: Follow the guide in [`docs/mcp-guide.md`](docs/mcp-guide.md).
2. **Deploy Skills**: Copy the required skills to your `.claude/skills/` directory.
3. **Anchor the Protocol**: Copy the template from [`templates/operating-protocol.md`](templates/operating-protocol.md) into your project memory.

## 📁 Repository Structure
- `/docs`: Deep dives into methodology and tool catalogs.
- `/config`: Templates for `.claude.json` and Desktop config.
- `/templates`: Reusable protocol and instruction templates.
