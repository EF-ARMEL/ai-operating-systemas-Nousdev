# 🌌 AI Operating System (AIOS)
### *The Ultra-High-Performance Framework for Autonomous AI Engineering & Design*

Welcome to the **AI Operating System**, a professional-grade architecture designed to transform a standard LLM into a high-precision autonomous agent. This project serves as a blueprint for setting up an environment where **Sourcing**, **Engineering**, **Design**, and **Validation** are handled by specialized tools and a rigorous protocol.

## 🚀 The Core Concept
AIOS moves away from "prompting and hoping" to a **Verifiable Workflow**. It integrates a suite of MCP servers and specialized skills to ensure that every line of code and every pixel of design is backed by real-time data and professional standards.

## 🚀 Quick Start

You can deploy the entire AI Operating System in 3 simple steps:

### 1. Infrastructure Setup
Run the automatic setup script to deploy all professional skills to your environment:
```powershell
powershell -ExecutionPolicy Bypass -File ./setup.ps1
```

### 2. MCP Installation
Install the necessary servers via the Claude CLI:
- **Sourcing**: `claude mcp add --transport http perplexity https://api.perplexity.ai/mcp`
- **Web Extraction**: `claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp`
- **Automation/QA**: `claude mcp add --transport stdio playwright -- npx @playwright/mcp@latest`
*(See [`docs/mcp-guide.md`](docs/mcp-guide.md) for full details and API keys)*.

### 3. Brain Activation
Copy the content of `templates/operating-protocol.md` and paste it into your **Claude Project Memory**. 

**That's it!** Your agent is now running the AIOS protocol. Just start your session and say: *"I'm ready for the first task!"*
