# 🎓 Skills Catalog

The AIOS utilizes a set of specialized skills to ensure professional-grade output. Skills are essentially "behavioral overlays" that change how the agent thinks and acts.

## 🛠 Technical Excellence
### `engineering-efficiency`
- **Focus**: Maintainability, Performance, Clean Code.
- **Usage**: Triggered for any bug fix or new feature.
- **Goal**: Minimize technical debt and maximize execution speed.

## 🎨 Design Mastery
### `awwwards-design-pro`
- **Focus**: High-end aesthetics, UX Psychology, Visual Rhythm.
- **Usage**: Triggered for any UI/UX modification.
- **Goal**: Create interfaces that feel "Premium" and intuitive.

## 🖼 Creative Suite (Higgsfield)
- **`higgsfield-generate`**: General purpose Image/Video/3D assets.
- **`higgsfield-brandkit`**: Comprehensive visual identities (logos, brandbooks).
- **`higgsfield-product-photoshoot`**: Studio-quality product photography.
- **`higgsfield-soul-id`**: Identity-faithful character generation.
- **`higgsfield-video-explainer`**: Narrated educational videos.
- **`higgsfield-marketplace-cards`**: E-commerce optimized visual assets.

## 🧠 Meta-Intelligence
### `task-observer`
- **Focus**: Process improvement and knowledge capture.
- **Usage**: Invoked at the start of every session.
- **Goal**: Analyze work habits to identify new skill opportunities and improve existing ones.

---

## 🚀 How to Load a Skill
In Claude Code, skills are loaded using the `/skill` command or automatically via the `project-operating-protocol.md` in the project memory.
